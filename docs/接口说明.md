# 接口说明（1.3 版）

本文件汇总对外接口：视觉流水线、检测器、串口协议、配置项。
更细的模块文档见 `src/detectors/color_api.md`、`src/detectors/shape_api.md`。

---

## 1. 视觉流水线 `src/core/pipeline.py`

### `VisionPipeline(config: PipelineConfig | None = None)`

构造时缓存颜色检测器与预处理器，适合逐帧调用。

| 方法 | 说明 |
|---|---|
| `run(image_bgr) -> FrameResult` | 执行一次完整检测 |
| `target_targets(result) -> list[Target]` | 按配置过滤出目标类别（默认红色圆形） |
| `set_config(config)` | 热更新配置并重建检测器 |
| `annotate(image, targets) -> ndarray` | 在图上绘制检测结果（静态方法） |

### `FrameResult`

| 字段 | 类型 | 说明 |
|---|---|---|
| `targets` | `list[Target]` | 全部目标，按面积降序、编号从 1 开始 |
| `timings_ms` | dict | `preprocess` / `color` / `shape` / `fusion` 各阶段耗时 |
| `total_ms` / `fps` | float | 总耗时与等效帧率（属性） |
| `masks` | dict | `color`：颜色掩码；`shape`：`{"rectangle": mask, "circle": mask}` |
| `debug` | dict | `color_count`、`shape_count`、`working_image` 等调试信息 |

### `Target`

| 字段 | 说明 |
|---|---|
| `id` | 目标编号（1 起） |
| `color` | `red/green/blue/yellow/orange/purple/unknown` |
| `shape` | `circle/rectangle/unknown` |
| `center` | `(x, y)` 像素坐标 |
| `width` / `height` / `radius` / `area` / `angle` | 几何量（像素 / 平方像素 / 度） |
| `confidence` | 置信度 0~1（颜色圆形度与形状质量的均值） |
| `source` | `color` / `shape` / `fusion` |
| `class_code` / `label` | 类别编码（如 17）与文本标签（如 `red_circle`） |

## 2. 颜色检测 `src/detectors/color.py`

```python
ColorDetector(target_color="red", min_area=100, confidence_threshold=0.3,
              enable_morphology=True, morph_kernel_size=5, dominance_ratio=0.0)

dets, mask = detector.detect_from_bgr(bgr_image, verbose=False)
```

| 参数 | 说明 |
|---|---|
| `target_color` | 支持 `red/green/blue/yellow/orange/purple` |
| `min_area` | 最小轮廓面积（像素²） |
| `confidence_threshold` | 置信度（= 圆形度）下限 |
| `dominance_ratio` | 主通道主导度门限；0 关闭，推荐 1.5（排除粉/品红/紫） |

返回的每个 dict 含 `id, color, center_x, center_y, width, height, area,
aspect_ratio, circularity, confidence, angle`；`mask` 为同尺寸二值图。

HSV 阈值（可自行调整）：红 `[0,100,100]-[10,255,255]` 与 `[160,100,100]-[180,255,255]`，
绿 `[40..80]`，蓝 `[100..130]`，黄 `[20..40]`，橙 `[10..20]`，紫 `[130..150]`。

## 3. 形状检测 `src/detectors/shape.py`

```python
rects, rect_mask = detect_rectangles(img_bgr, (h, w), min_area=150)
circles, circle_mask = detect_circles(img_bgr, (h, w), min_area=180,
                                      min_circularity=0.75, max_aspect_ratio_diff=0.2)
```

* 矩形判据：轮廓近似为 4 点、内角 70°–110° 且角度标准差 ≤ 15°、凸度 ≥ 0.8、宽高比 ≤ 10；
  返回 `center, long_side, short_side, aspect_ratio, angle, area, contour`。
* 圆形判据：圆形度 ≥ `min_circularity`、最小外接矩形长短边差 ≤ `max_aspect_ratio_diff`、
  且不是近方形；返回 `center, radius, diameter, circularity, area`。

> 注意：`img_shape` 必须是 `(height, width)`，与 `image.shape[:2]` 一致。

## 4. 串口协议 `src/comm/protocol.py`

### 帧格式（v1，14 字节）

| 偏移 | 字段 | 长度 | 说明 |
|---|---|---|---|
| 0 | 帧头 | 2 | `AA BB` |
| 2 | 长度 | 1 | 有效数据长度，v1 = 7 |
| 3 | 目标 ID | 1 | 0~255 |
| 4 | X | 2 | 小端，像素，0~65535 |
| 6 | Y | 2 | 小端，像素 |
| 8 | 置信度 | 1 | 0~100（= 置信度 × 100） |
| 9 | 目标类别 | 1 | 十位颜色、个位形状；红圆 = 17 |
| 10 | CRC16 | 2 | CRC-16/MODBUS，小端，校验 `LEN + 有效数据` |
| 12 | 帧尾 | 2 | `CC DD` |

v2（17 字节）：有效数据追加 `距离(2, mm) + 状态标志(1)`，`LEN = 10`；
标志 bit0 = 目标锁定，bit1 = 允许发射。

### 接口

```python
from src.comm.protocol import encode_target, FrameParser, crc16_modbus, decode_payload

frame = encode_target(1, 320, 240, 0.89, 17)                  # v1
frame = encode_target(1, 320, 240, 0.89, 17,
                      distance_mm=1250, flags=1)              # v2
parser = FrameParser()
frames = parser.feed(chunk)          # 分片/粘包/噪声都能处理
parser.stats.to_dict()               # frames_ok / crc_errors / tail_errors / ...
```

### 链路 `src/comm/link.py`

```python
from src.comm.link import make_link

link = make_link("COM3", 115200)     # 真实串口；port=None 时返回 NullLink
link.send_target(target)             # 自动编码并发送
link.close()

LoopbackLink()                       # 无硬件联调：发送后可直接解析回来
```

串口参数固定 8N1、115200（与协议文档一致）。

## 5. 配置 `src/core/config.py`

```python
PipelineConfig(
    preprocess=PreprocessConfig(enabled=True, color_mode="hsv_gamma",
                                shape_mode="none", target_luma=160.0),
    color=ColorConfig(colors=["red"], min_area=120, dominance_ratio=1.5),
    shape=ShapeConfig(min_circularity=0.75, min_circle_area=180),
    fusion=FusionConfig(max_center_distance=0.0, keep_unmatched_color=True),
    target_color="red", target_shape="circle",
)
```

预设：`default` / `lowlight` / `cluttered` / `realtime`，可用 `PipelineConfig.preset(name)` 取用，
或用 `load()/save()` 与 JSON 互转；命令行 `--preset` / `--config` 覆盖。

| 预处理模式 | 说明 |
|---|---|
| `none` | 不处理 |
| `denoise` | 高斯 + 中值 |
| `clahe` | LAB-L 通道 CLAHE |
| `clahe_sharpen` | CLAHE + 锐化（核和为 1） |
| `auto_gamma` | RGB 三通道 γ + CLAHE（会漂移色相，不推荐低照度用） |
| `hsv_gamma` | V 通道 γ + CLAHE +（可选）锐化，**低照度首选** |
